# شرح الشاطبية — مشروع LaTeX

شرح ميسّر لمتن الشاطبية بيتًا بيتًا، مع تلوين القراء والرموز، والأمثلة القرآنية، والتحريرات.
الجزء الحالي: المقدمة (١–٩٤)، الاستعاذة (٩٥–٩٩)، البسملة (١٠٠–١٠٧)، أم القرآن (١٠٨–١١٥).

## التشغيل على Overleaf
1. ارفع ملف الـ zip كما هو: **New Project → Upload Project**.
2. من **Menu → Compiler** اختر **XeLaTeX** (ملف `latexmkrc` يضبطه تلقائيًا غالبًا).
3. اضغط Recompile.

الخطوط (Amiri و Amiri Quran) موجودة داخل مجلد `fonts/`، فلا تحتاج تثبيت أي شيء.

## التشغيل على جهازك
```
latexmk -xelatex main.tex
```
أو شغّل `xelatex main.tex` مرتين (المرة الثانية لبناء الفهرس).

## هيكل المشروع
```
main.tex                  الملف الرئيسي (ترتيب الأبواب)
preamble/
  setup.tex               الحزم، الخطوط، تخطيط الصفحة، شكل العناوين
  colors.tex              ألوان القراء وألوان الصناديق (غيّر اللون هنا فقط)
  qurra.tex               أوامر أسماء القراء والرموز والآيات
  boxes.tex               أمر البيت \bayt وصناديق الشرح
frontmatter/              صفحة العنوان، دليل الاستخدام، المصادر
chapters/
  01-khutba/              المقدمة مقسمة إلى أربعة ملفات
  02-istiadha.tex
  03-basmala.tex
  04-fatiha.tex
  _template.tex           قالب جاهز لأي باب جديد
fonts/                    خطوط Amiri (رخصة OFL)
```

## إضافة باب جديد
1. انسخ `chapters/_template.tex` باسم جديد، مثل `chapters/05-idgham-kabir.tex`.
2. في `main.tex` أضف السطر: `\include{chapters/05-idgham-kabir}`.
3. أثناء الكتابة يمكنك ترجمة الباب وحده بتفعيل `\includeonly{chapters/05-idgham-kabir}` في `main.tex` (أسرع بكثير عندما يكبر الملف).

## الأوامر الأساسية
| الأمر | الاستعمال |
|---|---|
| `\bayt{108}{الشطر الأول}{الشطر الثاني}` | بيت الشاطبية في إطار ذهبي |
| `\qw{مالك}` | الكلمة القرآنية المختلف فيها داخل البيت |
| `\rz{Asim}{ناصر}` | كلمة فيها رمز قارئ، بلونه |
| `\rzg{صحبة}` | رمز جماعة |
| `\Asim`, `\Kisai`, `\Qalun` ... | اسم القارئ/الراوي ملونًا |
| `\ayah{...}` و `\src{الفاتحة: ٤}` | آية بالرسم العثماني ومرجعها |
| `mufradat` + `\kalima{}{}` | معاني الكلمات |
| `\maana` | المعنى |
| `qiraat` + `\qira{القراء}{القراءة}` | صندوق القراءات |
| `qaida`, `amthila`, `tahrir`, `tanbih`, `khulasa` | قاعدة، أمثلة، تحريرات، تنبيه، خلاصة |
| `\ithaf{رقم}{شطر}{شطر}` | بيت من إتحاف البرية داخل صندوق التحريرات |

مفاتيح الألوان: `Nafi, IbnKathir, AbuAmr, IbnAmir, Asim, Hamza, Kisai`.

**تنبيه تقني:** لوّن الكلمة العربية كاملة لا حرفًا منها؛ تغيير اللون في منتصف الكلمة يقطع اتصال الحروف في XeLaTeX.
